# Student Attendance Management System

A simple web-based Student Attendance Management System developed using HTML, CSS and JavaScript.

## Features

- Add new students
- Store student name and roll number
- Mark students as Present or Absent
- Save attendance records
- View attendance history
- Generate attendance reports
- Search attendance records
- Print attendance reports
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Pages

- Dashboard
- Students
- Mark Attendance
- Reports
